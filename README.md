# 📊 Dashboards de Control de Calidad

Dashboards ejecutivos interactivos para el control de calidad en recepción y salida de unidades.

## 🎯 Características

### Dashboard de Recibimiento (Incoming)
- 📋 Documentos registrados
- 📄 Cantidad en manifiesto
- 📦 Cantidad física recibida
- ⚠️ Piezas sobrantes o faltantes
- 📊 Gráficos de distribución por estado y coincidencia
- 📈 Evolución mensual con línea de tendencia
- 📄 Resumen ejecutivo exportable a PDF

### Dashboard de Salida (Outgoing)
- 📋 Documentos registrados
- 📄 Cantidad en manifiesto
- 📦 Cantidad física enviada
- ⚠️ Piezas sobrantes o faltantes
- 📊 Gráficos por estatus y tipo de envío
- 📈 Evolución mensual con análisis de tendencia
- 📄 Top 20 envíos por cantidad de pallets
